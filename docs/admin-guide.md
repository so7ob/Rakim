# دليل الإدارة — حالة الشريحة الأولى

الأدوار وقواعد الصلاحية وسجل التدقيق ممثلة في MariaDB. وضع التطوير الحالي يقبل رأس `x-user-role` لاختبار إنشاء المسودات فقط، ولا يصلح للنشر الشبكي أو الإنتاج. المصادقة بجلسة آمنة، واجهة دورة `INBOX → ... → ARCHIVED`، فصل المستورد عن المراجع والناشر، وإجراءات النشر لم تنفذ بعد وستغلق في المرحلة 4.

مدير النظام لا يحمل إذن `publish` أو `review` في بيانات البذر، امتثالًا لفصل الإدارة التقنية عن الاعتماد القانوني.
