# قاموس البيانات المختصر

| الجدول | الغرض | حقول حاكمة |
|---|---|---|
| `legislations` | الهوية الدائمة للتشريع | UUID، رمز العرض، الرقم المنشور، السنة، العنوان، الحالة، التواريخ، جهة ونوع وجريدة |
| `legislation_versions` | إصدارات المحتوى الكامل | رقم النسخة، حالة الدورة، فترة النفاذ، المصدر، `published_at` |
| `structure_nodes` | باب/فصل/قسم/فرع هرمي | الأب، النوع، العنوان، مفتاح الترتيب |
| `articles` | هوية المادة الثابتة | الوسم المنشور، مفتاح ترتيب مركب، العقدة البنيوية |
| `article_versions` | النص القانوني التاريخي | النص الأصلي/المنظم/حقل البحث، فترة النفاذ، الحالة، المصدر، السابق |
| `paragraphs` | هدف فقرة مرن داخل نسخة مادة | الوسم، الترتيب، النص، محدد مستقر |
| `amendments` / `amendment_operations` | أداة التعديل وعملياتها الصريحة | النوع، الأثر، المصدر، ترتيب التطبيق، الهدف |
| `article_modifications` | أثر العملية قبل/بعد | المادة/الفقرة، النصان، النسختان |
| `previous_text_snapshots` | العرض الموثق للنص السابق | النص، الفترة، سبب الانتهاء، المصدر |
| `annexes` / `annex_versions` / `annex_files` | اللوائح والجداول والملاحق الزمنية | النوع، الإصدار، الفترة، الملف، OCR، SHA-256 |
| `legal_relations` | علاقة موجهة بين تشريعين | النوع، الاتجاه الضمني، النطاق، الأثر، المصدر، المراجعة |
| `source_documents` | إثبات المصدر المنفصل | اسم آمن، MIME، SHA-256 فريد، تاريخ/جهة الاستلام، الصفحات |
| `search_documents` | فهرس MariaDB مشتق | نوع الكيان، النص الحرفي والمطبع، بيانات مرجعية، FULLTEXT |
| `users` / `roles` | الهوية والصلاحية | اسم الدخول، hash، الحالة، فصل الأدوار |
| `audit_logs` | أثر غير قابل للتحرير من الواجهة | الفاعل، الفعل، الكيان، قبل/بعد، السبب، الوقت |

النص المعروض لا يؤخذ من `search_documents`. هذا الجدول مشتق بالكامل ويعاد بناؤه من الجداول الأصلية.
