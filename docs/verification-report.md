| البوابة | النتيجة |
|---|---|

| `npm run seed` | نجح: 20 تشريعًا، 118 وثيقة بحث، 5 مستخدمين تطويريين |
| `npm run lint` | ناجح لكل workspaces |
| `npm test` | ناجح: 9 اختبارات وحدة/تكامل؛ تشمل التطبيع، تعارض التزامن، مناعة النص المنشور والحذف، والتدقيق |
| `npm run build` | ناجح: API وworker وReact/Vite |
| `npm run test:e2e` | ناجح: 15/15 حالة على 1440/1024/390، تشمل الرحلة الزمنية والتعديلات والملحق PDF والعلاقات والبحث العربي |
| axe | لا مخالفات WCAG A/AA آلية في الرئيسية والقائمة والبحث بالمقاسات الثلاثة في آخر تشغيل مكتمل |
| النسخ والاستعادة | نجح SHA-256 واستعادة معزولة: 20 تشريعًا، 90 نسخة مادة، 3 مصادر |
