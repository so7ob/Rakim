# خطة الاختبار

## بوابة المرحلة 0

- صحة الترحيل على MariaDB 10.11 و`utf8mb4`.
- رفض تداخل فترتين للمادة ورفض تعديل نسخة منشورة.
- وجود 20 تشريعًا اصطناعيًا على الأقل وتغطية الأنواع والحالات.

## بوابة الشريحة الرأسية الأولى

- وحدة: التطبيع العربي، تحليل الاستعلام، واختيار النسخة في تاريخ.
- API: الصحة، القائمة والفلاتر والترقيم، التفاصيل، الهيكل، المواد، البحث، وإخفاء المسودات.
- صلاحيات: رفض إنشاء تشريع دون دور، وعدم منح مدير النظام نشرًا افتراضيًا.
- واجهة: الانتقال من القائمة إلى المادة برابط ثابت وحالات loading/empty/error/offline.
- إتاحة: لوحة مفاتيح، رابط تجاوز، RTL، أسماء عناصر، وتباين آلي.
- لقطات: 1440 و1024 و390 و320، ومنع overflow آلي، وreflow مكافئ لتكبير 200% عند عرض CSS ‏512px.

## بوابة التاريخ والإدارة والاستيراد

- تزامن: طلبان يحاولان فتح فترة للمادة نفسها؛ يقبل واحد فقط ولا تتداخل الفترات.
- تعديل: الإدخال ثم المراجعة المستقلة ثم النشر المستقل ينشئ نسخة ولا يغير السابقة.
- صلاحيات: مجهول 401، دور غير مناسب 403، CSRF مطلوب، ومدخل البيانات لا ينشر.
- استخراج: fixtures فعلية لـTXT وDOCX وPDF نصي وصورة OCR عربية وCSV وXLSX.
- تشغيل: فحص Nginx/systemd، صحة العامل، نسخة ببصمات واستعادة في قاعدة مؤقتة، ثم إعادة الفهرسة.
- أمن التبعيات: `npm audit --omit=dev` في CI المتصل، مع منع الثغرات العالية/الحرجة.
