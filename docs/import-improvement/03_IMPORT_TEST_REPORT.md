## تغطية Parser

تشمل الحالات: باب/فصل/قسم، جميع تراكيب غياب المستويات، مواد فقط، title في السطر نفسه والتالي، الأرقام الغربية والعربية الهندية، الترتيب النصي، Unicode punctuation والمسافات، ورود «المادة» داخل النص، الانتقال من قسم إلى فصل ومن فصل إلى باب، root articles، heading غامض، ترتيب ظهور غير مطابق للأرقام، fallback بلا markers، وثبات النتيجة عند إعادة التحليل.

## تغطية التكامل

تحقق الاختبار من إسقاط preview الخفيف، وإنشاء parent IDs وترتيب العقد، وربط المواد بالقسم/الباب/root، وبقاء النص الأصلي، وقبول وسمين متكررين مع ترتيب مستقل، وaudit واحد، وإعادة طلب متزامنة تعيد التشريع نفسه، وrollback كامل عند علاقة غير صالحة.

## ملاحظات البيئة

الإصدارات الفعلية أثناء الاختبار: MariaDB 10.11.18 وnpm 10.8.2 وNode.js 20.20.0. الإصدار الأخير أقل من `engines.node >=22.13.0` المعلن، رغم نجاح الفحوص؛ يجب ألا يعتمد نشر Debian 12 على Node 20.

شغّل Playwright الكامل على منفذين معزولين (`4101/4274`) حتى لا يعيد استخدام خادم التطوير القائم ذي rate limit العادي. لا يتغير ضبط التشغيل الفعلي.
