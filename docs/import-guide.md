# دليل الاستيراد — حالة المرحلة الحالية

المخطط والطابور وحالات المصدر جاهزة، لكن رافع الملفات ومحللات DOCX/PDF/OCR لم تنفذ بعد؛ لا تستخدم قاعدة البيانات يدويًا لتجاوز المراجعة. المرحلة 3 ستطبق: تحقق الامتداد والحجم والبصمة، التخزين خارج الشفرة، استخراج محافظ، OCR عربي محلي، ثم مراجعة بشرية إلزامية قبل النشر.

الملف الممسوح التجريبي في البذر يحمل `OCR_UNREVIEWED` ولا يدخل الفهرس العام. Tesseract ليس مثبتًا في بيئة التطوير الحالية؛ عند تفعيل المسار ثبّت `tesseract-ocr tesseract-ocr-ara poppler-utils`.
