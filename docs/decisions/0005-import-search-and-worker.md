# ADR-0005: طابور MariaDB وفهرس بحث مشتق

- الحالة: مقبول
- التاريخ: 2026-09-04

## القرار

يحفظ المصدر خارج الشفرة وله SHA-256، بينما يحفظ MariaDB بياناته والنص المستخرج والمراجعة. يحجز عامل Node المهام بـ`SELECT … FOR UPDATE SKIP LOCKED` ويستعيد الحجز المتقادم، فلا يلزم Redis. OCR محلي عبر Poppler وTesseract العربي ولا يغير حالته إلى مراجع تلقائيًا.

البحث خلف `SearchProvider`. النسخة الأولى تستخدم `FULLTEXT` وحقولًا عربية مطبعة وجدول `search_tokens` للمواضع، وقاموس مرادفات مُصدرًا. `search_documents` مشتق ويمكن حذفه وإعادة بنائه من التشريعات والنسخ والتعديلات والملحقات والعلاقات.

## النتائج

OpenSearch خيار لاحق بعد قياس الحجم والأداء فقط، وليس متطلب تشغيل. النص الأصلي لا يطبع أو يستبدل لأجل البحث، والنسخ الملغاة تخفض افتراضيًا بدل حذفها.
