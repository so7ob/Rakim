# ADR-0004: جلسات محلية وفصل واجبات ملزم في الخدمة

- الحالة: مقبول
- التاريخ: 2026-09-04

## القرار

تستخدم الحسابات الإدارية كلمات مرور scrypt مملحة وجلسة عشوائية لا يحفظ منها إلا hash في MariaDB. يرسل المتصفح cookie من نوع HttpOnly وSameSite=Strict، ويلزم رمز CSRF مستقل لكل طلب يغير الحالة. الصلاحيات مستمدة من `user_roles` في كل طلب؛ لا توجد رؤوس أدوار تطويرية موثوقة.

قواعد المستورد والمحرر والمراجع والناشر تطبق داخل خدمات سير العمل والتعديل، وتسجل `workflow_responsibilities`. مدير النظام لا يرث الاعتماد القانوني أو النشر. إبطال الجلسات إلزامي عند تعطيل الحساب أو تغيير أدواره أو كلمة مروره.

## النتائج

إخفاء زر في React ليس حاجزًا أمنيًا؛ الرفض النهائي في API والمعاملة. النشر المؤسسي الخارجي يمكن أن يستبدل المصادقة لاحقًا خلف طبقة الهوية دون تغيير قواعد فصل الواجبات.
