# ADR 0007 — إعدادات العرض والمحتوى العام المدارة من قاعدة البيانات

الحالة: مقبول — 2026-09-04

## السياق

تحتاج المنصة إلى تعديل الهوية المرئية والترويسة والتذييل والتبويبات والصفحات العامة دون إعادة بناء الواجهة، مع بقاء كل تغيير منسوبًا إلى فاعله. وفي المقابل، لا يجوز أن تتحول لوحة الإعدادات إلى طريق لتجاوز ثبات النص القانوني المنشور.

## القرار

- تخزن `platform_settings` مفاتيح العرض المعروفة مسبقًا وقيمها JSON، وتتحقق الخدمة من النوع واللون والرابط قبل الحفظ.
- تخزن `navigation_items` روابط الترويسة والتذييل وترتيبها وظهورها، وتخزن `public_pages` محتوى الصفحات العامة وحالة نشرها.
- تقرأ React إعدادات العرض العامة من `GET /api/v1/site/config` وتطبق design tokens من CSS variables. لا تعرض الخدمة الإعدادات غير العامة.
- إعدادات الهوية والتنقل محصورة بمدير النظام؛ يستطيع مدير المحتوى تحرير ونشر الصفحات العامة. كل حفظ يولد `AuditLog` قبل/بعد مع السبب.
- رابط الشعار أو الخلفية يقبل HTTPS أو مسارًا محليًا يبدأ بـ`/` فقط؛ يبقى الشعار اليمني النصي الافتراضي متاحًا عند عدم وجود أصل مصرح.
- البيانات الوصفية المنشورة، ومنها بيانات الجريدة، يمكن تصحيحها بمدير المحتوى مع التدقيق. نص التشريع أو المادة المنشور لا يعدل في مكانه، بل عبر نسخة/تعديل زمني جديد.
- الأعداد مثل عدد المواد والتعديلات والملحقات، وآخر مراجعة، قيم مشتقة من سجلاتها وليست حقول إدخال مستقلة منعًا للتناقض.

## النتائج

يمكن تغيير الألوان والخلفيات وحجم النص القانوني والشعار والعناوين والروابط والصفحات فورًا دون نشر شفرة. وتبقى الهوية القانونية والتاريخية محمية بقيود النسخ والمعاملات، ولا تصبح إعدادات العرض مصدر حقيقة بديلًا.
