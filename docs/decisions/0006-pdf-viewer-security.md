# ADR-0006: عارض PDF.js محلي ومقيد بالإصدار

- الحالة: مقبول
- التاريخ: 2026-09-04

## القرار

يعرض React ملفات الملحقات عبر PDF.js بأصل محلي مبني، مع المصغرات والتنقل والتكبير والدوران والبحث والطباعة والتنزيل والشاشة الكاملة. رابط الملف يحدد `AnnexVersion` كي لا يعرض أحدث إصدار بدل المطلوب، ولا يكشف `storage_key`.

ثُبت `pdfjs-dist` على `5.5.207`: إصدار مصحح من مشكلة تنفيذ JavaScript في PDF الخبيث ومتوافق مع حد Node للمشروع. تتطلب سلسلة 6 المصححة Node 22.13 على الأقل ويمكن اعتمادها عند تحديث بيئة الإنتاج واختبار الانحدار.

## النتائج

يبقى التحقق من نوع الملف والحجم والبصمة قبل التخزين مطلوبًا. فشل الرسم يعرض metadata ورابط تنزيل واضح، ولا يجعل PDF بديلًا عن النص القانوني القابل للوصول.
