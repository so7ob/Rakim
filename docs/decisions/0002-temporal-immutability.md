# ADR-0002: نسخ زمنية غير قابلة للاستبدال

- الحالة: مقبول
- التاريخ: 2026-09-04

## القرار

كل مادة ذات هوية ثابتة، ونصوصها سجلات مستقلة في `article_versions` بفترة نصف مفتوحة `[valid_from, valid_to)`. تمنع مشغلات MariaDB تداخل الفترات، وتمنع تعديل نص نسخة منشورة. تطبيق تعديل يتم في معاملة تقفل المادة ونسخها ثم يغلق النسخة السابقة وينشئ نسخة جديدة وسجل عملية ولقطة سابقة وتدقيق.

## سبب الاختيار

القيود داخل قاعدة البيانات تحمي التاريخ حتى عند وجود كاتب آخر غير واجهة الويب، بينما يوفر قفل الصفوف حماية من سباق طلبين متزامنين.
