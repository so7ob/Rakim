# حالات التفاعل

| العنصر | default | hover/focus-visible | active/selected | disabled/loading/error |
|---|---|---|---|---|
| روابط الترويسة | كحلي، 13px/600 | لون الإجراء؛ tooltip للأدوات | `NavLink.active` بلون الإجراء | — |
| أدوات الترويسة | 32px دائرة شفافة | سطح وردي وتركيز 3px | إزاحة 1px | — |
| بحث الترويسة | 256×44 وتدرج شفاف | حلقة تركيز | إرسال إلى `/ar/search` | العبارة الفارغة لا تُرسل |
| درج الجوال | خارج الشاشة و`aria-hidden` | روابط بخلفية شفافة | `open` وتدرج كامل | Escape/الخلفية يغلقان |
| نافذة البحث | مغلقة | أول حقل يركز آليًا | `aria-modal=true` | Escape/الخلفية يغلقان |
| بطاقات الموضوع | تدرج محلي ونسبة 87% | تكبير الزخرفة وتحريك العنوان | رابط مرشح | حالة فارغة عند غياب الموضوعات |
| لوحات البيانات | سطح أبيض ورأس كحلي | الرابط خمري | — | تحميل/خطأ/فراغ بنص صريح |
| تصنيفات التشريعات | مجموعات `details` ومربعات اختيار | لون أساسي وتركيز ذهبي | `checked` يحدّث URL وAPI | «مسح التصنيفات» يعيد القائمة |
| صف التشريع | جدول بلا بطاقة | العنوان والأيقونات بلون الإجراء | رابط إلى النص | تنزيل/مشاركة/مفضلة تعمل أو تقود للدخول |
| فهرس القانون | روابط بفواصل وبحث داخلي | لون أساسي وخلفية وردية | `aria-current=location` و`:target` | زر تدوير يمسح البحث |
| سنة التعديل | بطاقة 80×107px على مسار زمني | ظل وتركيز واضح | `role=tab`, `aria-selected` وتدرج | الأسهم لا تتجاوز أول/آخر سنة |
| اللائحة/الجدول | صف مضغوط | زر دائري كحلي | `aria-expanded` و+/− | PDF/جدول/حالة ملف مفقود من API |
| علاقة التشريع | صف جدول | رابط التشريع بلون كحلي | `details` يكشف الدليل والنطاق | حالة فراغ عند غياب العلاقات |
| فهرس الدستور | روابط بفواصل | لون أساسي وpadding منطقي | `:target` يضيء القسم | بحث بلا نتائج برسالة |
| إجراءات الوثيقة | أيقونات بيضاء | دائرة بيضاء/لون أساسي | print/share/copy/back | Web Share يعود إلى Clipboard إذا غاب |
| المواد | نص قانوني مسطح داخل الوثيقة | رابط ثابت وأزرار النسخ السابقة | `:target` و`tabIndex=-1` | loading/error من API |
| العودة للأعلى | مخفي قبل 480px | تكبير/تركيز قياسي | ظاهر بعد التمرير | — |
| الحقول والأزرار العامة | حدود محلية | `:focus-visible` ذهبي 3px | حالات React/HTML | opacity 0.55 و`not-allowed` |

الانتقالات 180–300ms، وتُعطل آليًا عند `prefers-reduced-motion` وفي لقطات Playwright. جميع حالات الفتح تحمل `aria-expanded` أو `aria-modal`، وتغلق بـEscape.
