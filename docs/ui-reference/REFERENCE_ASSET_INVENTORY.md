# جرد أصول المرجع

تم توليد هذا الجرد من النسخة المحلية للقراءة فقط في `_reference/uae-legislation/`. العدد الفعلي: **155 ملفًا**. لا تُشغّل ملفات JavaScript المرجعية في المنتج أو أثناء الالتقاط.

## ملاحظات السلامة والاستخدام

- جميع الأصول في هذا الجدول محلية داخل الحزمة؛ توجد داخل HTML وروابط/أصول خارجية محظورة أثناء الالتقاط.
- اكتُشفت 363 مضيفات خارجية في صفحات الحفظ، تشمل الموقع المرجعي وأدوات تحليل/إتاحة، كما تتضمن ملفات الحفظ الكامل نطاقات إعلانية دخيلة لا صلة لها بالواجهة. لذلك يُحظر تنفيذ كل JavaScript المرجعي.
- ملفات الشعار والعلم والهوية الإماراتية مرجعية فقط وغير مستخدمة في المنتج اليمني.
- `DIN Next LT Arabic` موجود محليًا، لكن الحزمة لا تحتوي ملف ترخيص؛ لم يُنسخ إلى التطبيق، واستُخدم Cairo المرخّص ضمن اعتماد المشروع.
- «غير مثبت الاستخدام» تعني أن الاسم لم يظهر كمرجع مباشر في HTML/CSS/JS المحفوظ؛ لا تعني الحذف من المرجع.
