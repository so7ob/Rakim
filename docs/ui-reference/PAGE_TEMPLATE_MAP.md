# خريطة قوالب الصفحات

## القوالب المرجعية المنفذة

| المرجع | مسار المنصة | التنفيذ الحالي |
|---|---|---|
| `legislations.html` | `/ar/legislations` و`/ar/archived-legislation` | بانر داخلي، جدول تشريعات، صفوف متقطعة، عمود إجراءات، وشريط تصنيف يمين بعرض 376px |
| `legislations_1540_FULL.html` | `/ar/legislations/:id` و`/archived` | رأس قانون وبيانات وصفية، وثيقة بعرض 909.6px، فهرس يمين بعرض 376px، بحث المواد، روابط داخلية، نسخ تاريخية وطباعة |
| `legislations_1540_modifications_FULL.html` | `/ar/legislations/:id/modifications` | رأس موحد، خط زمني للسنوات، حالة سنة محددة، وبطاقات عمليات التعديل من API |
| `legislations_1540_regulations.html` | `/ar/legislations/:id/regulations` | قائمة لوائح/جداول مضغوطة، فتح وإغلاق، تنزيل وعارض PDF أو جدول منظم |
| `legislations_1540_related-legislations.html` | `/ar/legislations/:id/related-legislations` | جدول علاقات واتجاهها ورقم التشريع وسنته مع تفاصيل الدليل |
| `index.html` | `/ar` | الرئيسية المرجعية مع بيانات API |
| `constitution.html` | `/ar/constitution` | قالب وثيقة الدستور المنشور من MariaDB |

## القياسات المثبتة عند 1440px

- قائمة التشريعات: نهاية البانر `y=469`، بداية اللوحة `y=389`، عرض اللوحة `1285.6px`.
- جدول القائمة: `909.6px`، وشريط التصنيف: `376px`، ورأس الجدول: `64px`، والصف: `87px`.
- صفحة نص القانون: بانر `440px` بعد ترويسة `120px`، وبداية الوثيقة `y=480` بتداخل `80px`.
- الصفحات الفرعية: بانر `505px`، وبداية اللوحة `y=545` بتداخل `80px`.
- المحتوى والفهرس يستجيبان إلى عمود واحد تحت `820px`، ولا يوجد overflow أفقي حتى `320px`.

## الصفحات الممتدة بالنظام المستخرج

صفحات البحث، آخر التعديلات، الأخبار، السياسات، التعريف، الاتصال، حالات الخطأ والصفحات الإدارية تستخدم النظام المشترك. لا يوجد لبعضها HTML مطابق داخل ZIP، ولذلك لا يُدّعى لها تطابق مباشر. لا يتصل أي مسار بالموقع المرجعي ولا يحمل هوية أو محتوى إماراتيًا.
