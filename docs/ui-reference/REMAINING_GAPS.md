# الفروقات المتبقية الحقيقية

1. خط المرجع هو `DIN Next LT Arabic`، لكن ملفات الحزمة لا تحمل ترخيص استخدام؛ لذلك بقي المنتج على Cairo المحلي المرخّص. ينتج عن ذلك اختلاف محدود في عرض الحروف والتفاف العناوين.
2. هوية المرجع الإماراتية محجوبة عمدًا. يستعمل المنتج هوية المنصة اليمنية و`LegislationDocumentMark` محليًا مع الحفاظ على المساحة، ولذلك تختلف منطقة الشعار والأختام رسميًا وبصريًا.
3. محتوى قاعدة التطوير اليمنية وعدد المواد والتعديلات واللوائح والعلاقات يختلف عن محتوى الصور الإماراتية؛ لذلك تختلف أطوال النص وعدد الصفوف والسنوات رغم تطابق القالب والقياسات الأساسية.
4. إعدادات ألوان المنصة مخزنة في MariaDB وقابلة للتعديل. اللقطات المباشرة للمقارنة تُثبت لوحة المرجع `#AC4459/#344B61`، بينما التشغيل العادي يحترم قرار الهوية المحفوظ حاليًا في قاعدة المنصة.
5. القياس المباشر للصور السبع المرفقة عند 1440×1000 أعطى فرق luminance خامًا بين 2.317% و7.381%. قائمة التشريعات هي 2.317%، وبقية الفرق يتركز في الهوية والنصوص وأعداد السجلات؛ لذلك لا يُدّعى بلوغ 1–2% لجميع الصور.
6. الالتقاط الآلي للـHTML المحفوظ بلا JavaScript لا يعيد دائمًا الحالة الحية نفسها للبانر والقوائم؛ الصور المرجعية الخارجية تبقى محليًا في `_reference/provided-screenshots/` وتُقارن بمسار مستقل دون رفعها إلى Git.
7. قاعدة التطوير لا تحتوي مواد دستور يمني مهيكلة بالكامل ولا عداد «الأكثر اطلاعًا». الواجهات تعرض البيانات الموجودة وحالات فراغ صريحة ولا تختلق محتوى أو ترتيبًا.
8. صفحات عامة لا توجد لها ملفات HTML كاملة داخل ZIP تستخدم امتداد نظام التصميم، دون ادعاء مطابقة Pixel-Perfect.
