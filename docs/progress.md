- [x] مسارات نظيفة للتنزيل والأرشيف وآخر التعديلات والدستور والمنظومة والسياسات والأخبار والصفحات الثابتة واستعادة كلمة المرور.
- [x] عارض PDF.js محلي بالمصغرات والتنقل والتكبير والملاءمة والدوران والبحث والطباعة والتنزيل والشاشة الكاملة وفشل آمن.
- [x] بحث MariaDB عربي حرفي/موسع، كل/أي/استبعاد، حقول، قرب، تاريخ، نسخ تاريخية، facets وتحليلات وCSV وقاموس مرادفات مُصدر.
- [x] جلسات آمنة وCSRF وCORS وRBAC وقفل الدخول وتغيير كلمة المرور وأدوات الباحث.

- [x] إعدادات منصة من MariaDB للاسم والشعار والألوان والخلفية والخط وأدوات الترويسة والتذييل وتبويبات التشريع، ومحرر صفحات عامة متعدد الأقسام.

## قيود معلنة لا تفقد بيانات

- القراءة النصية الآلية للمرجع محجوبة بـ403، لكن الالتقاط التفاعلي نجح ووُثق؛ عناصر P1 تبقى `ADAPTED` لأن الهوية والمحتوى والأصول يمنية أصلية وليست نسخًا بكسليًا.
- تحليل البنية المستوردة محافظ؛ الحواشي والجداول المعقدة ومحددات فقرات الوثائق غير المنتظمة تحتاج مراجعة بشرية، كما تقتضي دورة المحتوى.
- تظليل نتيجة PDF في موضع هندسي دقيق يعمل فقط حين تتوفر إحداثيات موثوقة؛ بيانات البذر النصية تفتح الصفحة وتظهر مطابقة البحث ولا تدعي إحداثيات غير موجودة.
- هدف الأداء مقاس على عينة التطوير (118 وثيقة)، وليس إثبات سعة أرشيف وطني. واجهة `SearchProvider` تسمح بمزود لاحق دون تغيير مصدر الحقيقة.
- Docker Compose لم يضف لأنه اختياري، بينما مسار Debian المباشر مكتمل ومختبر صياغيًا.

القبول البصري الحالي موثق بلقطات المرجع واللقطات المحلية وخطوط أساس Playwright؛ أي اعتماد مؤسسي نهائي للهوية والنصوص يحتاج بيانات وشعارًا مصرحًا بهما.
