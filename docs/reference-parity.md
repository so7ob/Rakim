# سجل التطابق المرجعي الحي

## عائق الرصد المتبقي

الحالة الخارجية `BLOCKED`: المقارنة البصرية المباشرة مع المرجع. الإجراء عند توفر شبكة مسموحة: أخذ لقطات مؤرخة 1440/1024/390 لكل صفحة، مقارنة المسافات والحالات والتفاعلات، ثم تغيير الصف المطابق إلى `MATCHED` أو إبقاء `ADAPTED` مع فرق محدد. هذا العائق لا يمنع تشغيل أو اختبار وظائف المنصة.
