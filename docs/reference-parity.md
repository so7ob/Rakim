## نتيجة الرصد

لم يعد الوصول المرجعي محجوبًا على مستوى المتصفح التفاعلي. تبقى الحالات `ADAPTED` لأن الهوية والأصول والنصوص محلية عمدًا، ولأن بعض صفحات المرجع لا تعرض حالة هاتف عامة يمكن اعتمادها دون حساب أو بيانات إضافية. قبول المنصة يعتمد سجل المتطلبات واختبارات الوظيفة والإتاحة والاستجابة، مع استخدام اللقطات دليلًا لترتيب المعلومات والمسافات والحالات المرئية.
