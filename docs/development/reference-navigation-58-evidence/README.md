# توحيد مدخل القوائم المرجعية — Issue #58

أصبح التنقل الجانبي يحتوي مدخلاً واحداً باسم «القوائم المرجعية» إلى `/ar/admin/reference-data`، بدلاً من ثلاثة مداخل لأنواع التشريعات والتصنيفات والموضوعات والجهات. تبقى الأقسام تبويبات داخل الصفحة، ويظل المدخل نشطاً في جميع مساراتها، بما فيها أعداد الجريدة. يستمر تطبيق `reference.view` دون تغيير في الخادم أو قاعدة البيانات أو المنح.

- اختبارات Playwright الحالية للتنقل والقائمة المحمولة: 3 ناجحة و5 تخطيات شرطية حسب حجم الشاشة.
- تحقق متصفح مباشر بعرضي 1440 و390: مدخل واحد، اختفاء المداخل الثلاثة من الجانب، نجاح التحويل إلى تبويب الأنواع، استمرار التبويبات الداخلية وتمييز المدخل نشطاً في المسارات الأربعة.
