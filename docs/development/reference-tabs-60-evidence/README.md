# ثبات ترتيب تبويبات القوائم المرجعية — Issue #60

كان تبويب «أعداد الجريدة» ينتقل من أول الشريط إلى آخره بسبب تعريفين مختلفين للتبويبات. يستخدم القسمان الآن `ReferenceDataTabs` المشترك مع `AdminTabs`، بترتيب ثابت: أعداد الجريدة، أنواع التشريعات، التصنيفات والموضوعات، الجهات. تُمرر العدادات من استجابة API القائمة أيضاً إلى صفحة أعداد الجريدة، فتحافظ على ظهورها أثناء التنقل.

التحقق بتاريخ 2026-09-09 على بيانات معزولة:

- بناء الواجهة وفحص TypeScript وPrettier: ناجحة.
- اختبارات الواجهة الحالية: 11 ناجحاً.
- Playwright مباشر على أحجام 1440 و1024 و390 و320: التنقل بالنقر بين الأقسام الأربعة، وثبات ترتيب الروابط ونصوصها وعدّاداتها، وصحة التبويب النشط، واستمرار النتائج بعد إعادة التحميل.

- `npm run visual:admin`: 144 عرضاً ناجحاً دون أخطاء console/network/HTTP أو تجاوز أفقي.
